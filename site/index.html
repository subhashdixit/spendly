How this works · scope and limitations

Money is parsed as decimal text and stored in integer paise, avoiding floating-point rounding in totals. Imports are validated as a complete set before replacing the current workspace. This browser data is unencrypted and visible to anyone using the same browser profile. No original account database is published.
